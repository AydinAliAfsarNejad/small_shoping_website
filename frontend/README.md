# فروشگاه نمونه — نسخه‌ی فرانت‌اند (استاتیک)

- index.html — صفحه اصلی / فهرست محصولات (جستجو + دسته‌بندی + Swiper پیشنهادها)
- product.html — جزئیات محصول (?id= شناسه محصول)
- auth.html — ورود / ثبت‌نام (نمایشی)
- profile.html — پروفایل و آدرس (نمایشی)
- cart.html — سبد خرید و تسویه‌حساب (localStorage)

## ری‌برندینگ
- هویت بصری فقط در `static/css/design-tokens.css` (توکن‌های `--color-*`, `--radius-*`, فونت) تعریف شده است.
- محصولات، هزینه ارسال و آستانه ارسال رایگان در ابتدای `static/js/app.js` (`STORE` و `PRODUCTS`) قرار دارند.

## نکته
سبد خرید سمت مرورگر است و فقط برای پیش‌نمایش فرانت‌اند. نسخه‌ی نهایی با
بک‌اند Django در پوشه‌ی جداگانه (`store-django`) موجود است؛ در آنجا قیمت‌ها و
موجودی فقط سمت سرور اعتبارسنجی می‌شوند.
